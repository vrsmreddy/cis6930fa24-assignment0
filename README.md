Assignment Description:

This project involves creating a Python application to interact with the FBI's Most Wanted API, process the retrieved data, and handle various input scenarios. The application supports fetching data from the API, loading data from local JSON files, and formatting the data for output. This project demonstrates proficiency in API interaction, file handling, data formatting, and testing.

How to Install:

To set up the project environment and install the necessary dependencies, follow these steps:

Clone the Repository:

git clone [repository_url]

cd [repository_directory]

Install Dependencies:

Use Pipenv to install all required packages and create a virtual environment:

pipenv install -e .

This command installs the dependencies specified in the Pipfile and sets up the virtual environment for the project.

How to Run:

The application provides two main functionalities: fetching data from the FBI API or loading data from a local JSON file. Use the following commands to execute the program:

Fetch Data from the API:

pipenv run python main.py --page <PAGE_NUMBER>

--page <PAGE_NUMBER>: Specifies the page number to fetch data from the FBI API.

Replace <PAGE_NUMBER> with the desired page number. For example, to fetch data from page 3, use --page 3.

Example:

pipenv run python main.py --page 3

This command will fetch data from page 3 of the FBI API and print the formatted results.

Load Data from a Local JSON File:

pipenv run python main.py --file <FILE_LOCATION>

--file <FILE_LOCATION>: Specifies the path to a local JSON file to load data from.

Replace <FILE_LOCATION> with the path to your JSON file. For example, if you have a JSON file named fbi_page_3.json in the tests directory, use --file tests/fbi_page_3.json.

Example:

pipenv run python main.py --file tests/fbi_page_3.json

This command will load data from the specified JSON file and print the formatted results.

File Path Errors: Incorrect file paths or permission issues may prevent loading data from local files.

Data Validation: The application assumes that the API and local files provide data in a consistent format. Unexpected changes in data structure may cause errors.

Assumptions

JSON File Format: Assumes that the JSON files used for testing are correctly formatted and include the necessary fields (title, subjects, field_offices).

API Data Structure: Assumes that the API will return data in the expected format and will handle high page numbers correctly.

Valid Inputs: Assumes that valid page numbers and file paths will be provided when running the application.

API Rate Limits: Assumes that the API does not have strict rate limits that would affect the testing process.
